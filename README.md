# קורא הודעות ושיחות (VoiceAnnouncer)

אפליקציית אנדרואיד שמקריאה בקול:
- שם המתקשר (מאנשי הקשר) בשיחה נכנסת, עם חזרה על ההכרזה בזמן הצלצול
- כל הודעה שמגיעה (SMS, וואטסאפ, טלגרם, מייל ועוד), עם אפשרות להקריא גם את התוכן

היא עובדת גם כשהאפליקציה סגורה, כי המערכת מפעילה את שירות ההאזנה להתראות ואת מקלט השיחות בעצמה.

## הגדרות
- קריאה רק כשמחובר התקן בלוטוס (אוזניות, רמקול, מערכת רכב)
- בחירת אפליקציות שיוקראו וחסימת אחרות
- הקראת כל ההתראות או רק הודעות
- מהירות וגובה קול
- שעות שקט להודעות (שיחות נכנסות תמיד מוכרזות)
- כפתור בדיקת קול

## בניית ה-APK

### דרך א: Android Studio
1. File > Open ופתיחת התיקייה VoiceAnnouncer
2. המתנה לסיום Sync
3. Build > Build Bundle(s) / APK(s) > Build APK(s)
4. הקובץ ייווצר ב: `app/build/outputs/apk/debug/app-debug.apk`

### דרך ב: בנייה בענן (בלי להתקין כלום)
1. העלאת התיקייה למאגר GitHub חדש
2. לשונית Actions > Build APK > Run workflow
3. בסיום להוריד את הקובץ מ-Artifacts (VoiceAnnouncer-apk)

## התקנה והפעלה ראשונה
1. העתקת ה-APK לטלפון ופתיחתו (נדרש לאשר התקנה ממקור לא ידוע)
2. פתיחת האפליקציה ולחיצה על שלושת הכפתורים העליונים לפי הסדר:
   גישה להתראות, הרשאות, וביטול חיסכון בסוללה
3. בדיקת קול

## הערות
- בחלק מהמכשירים (שיאומי, סמסונג ועוד) צריך גם לאפשר "הפעלה אוטומטית" או "ללא הגבלות ברקע" בהגדרות האפליקציה, אחרת יצרן הטלפון עלול לסגור אותה.
- המספר של המתקשר זמין רק עם הרשאת יומן שיחות. בלי ההרשאה האפליקציה תכריז "שיחה נכנסת" בלבד.
- קול בעברית תלוי במנוע ההקראה של הטלפון (Google Text-to-speech עם חבילת עברית מותקנת).
