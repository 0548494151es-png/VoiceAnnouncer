# קורא הודעות (VoiceAnnouncer)

אפליקציית אנדרואיד שמקריאה בקול שם מתקשר והודעות נכנסות (וואטסאפ / SMS / טלגרם), גם כשהאפליקציה סגורה.

## מה יש בה
- עובדת ברקע גם כשהאפליקציה סגורה (שירות קבוע, הפעלה אוטומטית אחרי הדלקת הטלפון)
- ממשק צבעוני בעברית
- אפשרות להקריא רק בבלוטוס, ולא להקריא בשקט / רטט
- בחירת קול, גובה קול (נמוך = גברי) ומהירות
- עדכון מתוך האפליקציה: כפתור "בדוק עדכון" ← "הורד והתקן"

## איך מעדכנים את האפליקציה בעתיד
1. מעלים לריפו קבצים חדשים (Add file ← Upload files)
2. ב-Actions נבנית גרסה חדשה ומתפרסמת אוטומטית ב-Releases
3. באפליקציה: "בדוק עדכון" ← "הורד והתקן"

## חשוב
- קובץ החתימה `app/release.jks` חייב להישאר בריפו ולא להשתנות - בלעדיו לא ניתן לעדכן מעל הגרסה הקיימת.
- אם הריפו פרטי: צריך להזין באפליקציה טוקן GitHub (Fine-grained, הרשאת Contents: Read-only). אם הריפו ציבורי - לא צריך.
